§ 02 / Campaign types
How we deploy creators

Four campaign archetypes. One system of accountability.

Archetype 01

Launch raid

6–20 creators, 10-day window, one coordinated push. Used for product launches & bursts.

10 days · ₹5–18L
Archetype 02

Always-on drip

2–4 creators/month, ongoing. Builds brand recall and steady top-of-funnel.

Monthly · ₹3L+
Archetype 03

Ambassador tier

Long-form deals with 3–5 creators. Usage rights, exclusivity, affiliate-style splits.

6–12 mo · Negotiated
Archetype 04

Event & UGC push

Creator-led activations IRL. Store openings, pop-ups, tastings, launches.

Per event · ₹4L+
