Read it top to bottom. Build it in the same order.

This brief is structured to be fed into Lovable in sequence. Each part builds on the one before it, so the design system is locked before any page is generated.

  1. Start with the Master Prompt (§02). Paste it first to seed the project: it sets the brand, the dark design system, the stack, and the global rules Lovable should apply to everything.
  2. Lock the Design System (§03). Paste the tokens prompt so colors, type, spacing, and components exist as reusable styles before any page is built.
  3. Generate pages one at a time (§05+). Each page has its own paste block. Build Home first, then About, Careers, the three service pages, and Contact. Generating one page per prompt keeps Lovable focused and the output consistent.
  4. Apply the sitewide checklist (§06) as a final pass: navigation, CTAs, SEO, accessibility, responsive behavior.
How to read the blocks

01 · Project at a glance

What SeeTusk is, and what we are changing.

The studio

SeeTusk Creative Agency (SCA) is a Pune-based creative distribution studio. It does three things and ties them together: makes the content, runs the creator campaigns, and builds the websites and tools that turn attention into customers, all shipped on a weekly rhythm.

Sitewide one-liner (use verbatim, everywhere):

Approved positioning line

"SeeTusk helps growing Indian brands get seen and chosen through content, creator campaigns, and websites that convert."

Audience

Founders and marketing leads at growing Indian brands (D2C, FMCG, HoReCa, real estate, tech/SaaS, education). Cold visitors who must understand the offer within the first screen, plus talent visiting Careers.

4th service"Campaigns" links to Contact, no pageReal destination for Campaign Launches
Case studies"View case" points to service pagesReal case detail (page or drawer)
Keep — the brand signature

The hero concept stays: "OWN. BUILD. RENT. DISTRIBUTION FOR AMBITIOUS BRANDS." It is distinctive and worth keeping. The plain support line beneath it carries the literal meaning for cold visitors.

Primary goals for the rebuild

  • A first-time visitor understands what SeeTusk does, who it serves, and where to go next within the first screen.
  • All four service paths are visible above the fold and every one is reachable.
  • Proof (results, cases, testimonials) comes before team detail.
  • Every CTA opens a real, intent-matched destination.
  • Motion-rich but accessible: reduced-motion support, visible focus, strong contrast on the dark base.

POSITIONING (use this exact line on the site): "SeeTusk helps growing Indian brands get seen and chosen through content, creator campaigns, and websites that convert." VISUAL LANGUAGE — dark, technical, premium: • Backgrounds: primary #0B0B0D, secondary #111214, cards #1B1D20. • Text: primary #FFFFFF, secondary #B7BDC6, muted #80858D. • Accents: primary #4F8CFF (CTAs + highlights), secondary #7A5FFF, highlight #58D5FF. • Signature gradient: #4F8CFF → #7A5FFF (add #58D5FF for buttons). LAYOUT RULES (apply globally): • Max content width 1280px; paragraph reading width 760–820px. • 12-column grid desktop, 8 on tablet, 4 on mobile. • Section vertical padding 120px desktop / 80 tablet / 64 mobile. Side padding 32 / 24 / 20. • Cards: radius 20px, padding 32px, 1px border rgba(255,255,255,0.08), hover lift + soft shadow. • Buttons: height 52px, radius 12px; filled / outline / text variants; 200ms hover. • Every section follows the order: small label → H2 → description → content → CTA. MOTION: page-load fade-up 0.6s, card hover scale to 1.03, button hover 200ms, headline text reveal 40ms stagger. Always respect prefers-reduced-motion. I will give you the tokens, then each page, one at a time.

Seeding the system before any page keeps every later screen consistent. Resist letting Lovable generate pages from this prompt; the next section locks the tokens as reusable styles.

04 · Global shells & components

Patterns every page reuses.

Navigation (identical on every page)

Client-focused top nav. Keep it the same across all pages. Careers and Contact live in the footer, not the top nav.

Top nav

Logo (SeeTusk / SCA) left. Links: Content · Creators · Web & Tech · About. Primary "Start a project" button right (filled gradient). Sticky, glassy on the dark base, blur backdrop.

Mobile nav

Hamburger → full-screen overlay, large stacked links, gradient CTA at the bottom. Visible focus, trap focus while open.

Heading accessibility

Do not split headings letter-by-letter in the DOM (the stacked "Seetusk / Creative / Agency" wordmark and the kinetic hero). The accessible name must read as whole words for screen readers and crawlers, even if the visual animates per letter.

Section scaffold (use for nearly every section)

Order

Small numbered/uppercase label → H2 → one-line description → content → optional CTA. This is the standard rhythm; keep it consistent.

Section number motif

Keep the "001 / 002 / 003" monospace section counters as an accent in the muted/blue color. They give the technical, editorial feel.

Footer (every page)

Dark footer with: brand block + the footer description below, link columns (Verticals / Studio / Elsewhere), social icons (YouTube, X, Instagram, LinkedIn), and the newsletter signup. Newsletter lives in the footer only, never stacked against the final CTA.

Accessibility checklist

  • Honor prefers-reduced-motion on hero, marquee, and all scroll/ticker motion.
  • Visible keyboard focus on nav links, service/case cards, FAQ accordions, and every CTA.
  • Each card is a single link with a clear accessible name, not a block of separate clickable fragments.
